01 / MUSEUM WEBSITE

NANJING MUSEUM ADMINISTRATION

南京市
博物总馆网站

以「建筑、馆藏、文化传播」为设计线索，重构总馆概况、展览、藏品、学术、教育与公众服务的数字入口。

TYPE
文博门户网站
SCOPE
30 张页面 / Icon System
02DESIGN CONCEPT

让建筑的轮廓，
成为网站的第一语言。

首页以博物馆屋檐曲线为核心识别，通过黑、白、灰与朱红印章建立宁静而具文化感的视觉秩序。展览与内容页则让藏品和历史图像成为主角。

03COLLECTION-INSPIRED ICONS

从馆藏中提取符号，
构建一套文化 Icon。

Icon 并非通用图形的直接套用，而是从博物馆建筑和藏品中提取造型，再统一为轻量线性语言。

檐

建筑屋檐

总馆标识与屋檐曲线形成「关于总馆」的核心记忆点。

鼎

青铜与文物

将青铜器、瑞兽、陶瓷器等馆藏外形转译为展览与藏品符号。

线

统一线性语法

使用等线宽、圆形容器和克制灰阶，平衡文化个性与导航可读性。

04 / WEBSITE SYSTEM

从参观信息，
到文化内容的完整路径。

A

总馆与参观服务

建立总馆介绍、组织信息、分支机构和导览入口。

B

资讯与学术研究

用统一的列表、详情与人物模板组织新闻和学术内容。

C

展览与馆藏

以大幅历史图像和留白形成叙事感，让展览和藏品成为视觉中心。

D

公众教育与参与

用讲堂、夏令营、主题活动与志愿者服务，将博物馆从展示空间延伸为公众文化平台。
