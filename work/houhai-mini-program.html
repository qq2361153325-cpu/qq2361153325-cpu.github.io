01 / PROJECT OVERVIEW

PROJECT BACKGROUND

把分散的城市内容，
整理为可行动的生活入口。

后海片区同时存在文化活动、公园驿站、场馆预约、商圈消费和社区交流等多类服务。项目需要在一个轻量的小程序中，让用户既能浏览内容，也能快速完成导航、预约、购票和下单。

设计重点不是单独完成某一个页面，而是让地图、内容、服务和交易共享同一套信息结构，并在高频入口与丰富内容之间取得平衡。

01

入口过多

活动、地图、场馆、商圈、商城和社区均需要被发现，首页容易变成信息堆叠。

02

场景跨度大

用户可能处于“先浏览”“找地点”“预约服务”或“直接消费”等不同任务状态。

03

路径要闭环

从内容种草到地图到达、预约确认和订单管理，需要保持连续且可追溯。

02 / HOMEPAGE EVOLUTION

DESIGN ITERATION

首页不是选一张最好看的，
而是逐步收敛主任务。

素材中包含多套首页方案。案例中将它们作为设计过程保留：从功能聚合，到内容丰富，再到最终突出“生活地图”和“活动预约”两个核心入口。

VERSION A · 功能聚合

先覆盖服务范围

入口完整，但功能数量较多，用户需要先理解分类，再决定下一步。

VERSION B · 内容增强

增加城市内容密度

活动与商圈曝光更充分，但首屏仍有多个同级模块争夺注意力。

PLAN C · 最终方向

聚焦两项主任务

用“生活地图 + 活动预约”建立明确首屏路径，热门推荐承担内容种草。

最终选择 Plan C

它没有删除业务，而是把低频能力放入地图分类、活动频道和个人中心中，让首页先回答“去哪里”和“做什么”。

03 / EXPERIENCE ARCHITECTURE

以地点和活动为双线，
串联城市生活服务。

地图解决“附近有什么、怎么到达”，内容解决“什么值得参加”，预约与商城则完成服务转化。

01

HOME & MAP

首页负责选择方向，
地图负责进入现场。

最终首页使用清晰的双入口降低决策成本；地图页以类别、区域和关键词筛选地点，并支持从地图标记直接进入场馆或活动详情。

双主入口

生活地图与活动预约占据首屏核心位置。

分类可视化

公园、咖啡、文体、服务、商场等采用统一图形编码。

地图到内容

地图标记、地点卡片与详情页保持连续跳转。

02

ACTIVITY DISCOVERY

把日期、地点和类型，
变成可快速比较的活动信息。

活动页通过日期滑动、关键词搜索和分类筛选提高浏览效率。详情页集中展示时间、地址、价格、活动介绍与购买须知，并保持底部购买操作持续可见。

  • 日期优先支持按今天、周末或日历快速定位。
  • 标签筛选免费、亲子、演出、LIVEHOUSE 等场景可直接切换。
  • 转化固定收藏与立即购买固定在底部，阅读过程中随时行动。
03

VENUE BOOKING

把筛选、日期、场次和人数，
拆成稳定的预约步骤。

列表适合快速比较，详情页补充距离、开放时间与场地说明；预约阶段再逐步选择日期、场次和人数，避免一次呈现过多规则。

04

LOCAL PLACES

用一致的卡片体系，
覆盖商圈、公园驿站与场馆。

不同地点共享距离、地址、开放时间、联系方式和相关活动等信息结构。用户从地图、首页或列表进入后，都能快速判断是否值得前往。

05

SHOP & ORDERS

让本地文化内容，
延伸到商品和订单服务。

商城延续小程序的圆角卡片和蓝色操作体系，支持规格选择、快递或上门自提、订单确认、支付与完成状态，形成从商品浏览到交易完成的独立闭环。

  • 商品发现用分类、推荐与内容化卡片缩短浏览路径。
  • 购买决策规格、价格、配送方式和服务说明集中呈现。
  • 订单反馈确认、支付与完成状态保持连续且可追踪。
04 / DESIGN PRINCIPLES

用轻量视觉承载复杂城市服务。

设计语言保持明亮、亲和与易识别，确保地图、内容与交易页面在同一产品中仍然具有统一感。

01

任务优先

首页突出高频入口，低频能力进入频道和个人中心。

02

地点可行动

地图标记不仅展示位置，还能直接进入地点与活动服务。

03

模块复用

活动、场馆、商圈和商品共享稳定的卡片与详情结构。

04

状态明确

筛选、日期、场次、订单和预约结果都有清晰反馈。

05 / SELECTED CORE SCREENS

CORE PAGE COLLECTION

精选 30 个核心页面，
展示完整产品覆盖度。

首页不同版本保留为设计迭代，其余页面按地图、活动、预约、场所、商城和账户分类。点击任意页面可查看完整设计稿。

06 / PROJECT SUMMARY

DESIGN SUMMARY

从页面集合，
到城市服务体验系统。

看后海小程序的核心价值，是将地图、活动、预约、场所和交易从分散入口整合为连续体验。

首页多版本的迭代也反映了设计重点的变化：不是不断增加内容，而是识别真正的高频任务，再让其他服务围绕主路径自然展开。
