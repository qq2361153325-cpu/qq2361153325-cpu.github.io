01 / PROJECT OVERVIEW

A LOCAL LIFE OPERATING SYSTEM

让片区生活信息、消费服务和企业权益集中在同一个入口。

项目不是单一的旅游或商城产品，而是服务西岑居民、企业员工与到访游客的生活圈平台。

用户可以发现本地商户与活动、购买景点门票、查看生活地图、完成日期与票种选择，也能通过企业身份认证获得专属权益。设计需要同时兼顾内容浏览、工具效率和会员经营。

01

服务类型复杂

美食、旅游、民宿、教育、医疗、配套服务与人才公寓需要统一组织。

02

地图与内容联动

用户既要在地图上查找点位，也要快速进入列表、筛选和详情。

03

企业权益独立

VIP 认证既要完成企业与员工身份校验，也要保持流程清楚可信。

02 / LIFE CIRCLE PATH

DISCOVER · LOCATE · BOOK · VERIFY

以生活地图为中轴，连接五类核心任务。

01发现西岑首页 / 内容聚合 02探索商户商户 / 套餐 / 优惠 03预订票务景点 / 日期 / 票种 04地图导览分类 / 点位 / 列表 05认证权益企业 / 员工 / 会员
01

DISCOVERY HUB

首页先建立片区印象，再把高频生活任务前置。

首屏用区域视觉和生活地图、景点购票、活动召集等入口形成快速分流；长页面继续承载每日特惠、旅游、美食、住宿和精彩推荐。

  • 区域识别以青浦与西岑视觉建立明确的在地感。
  • 高频入口地图、购票、活动和公共服务优先展示。
  • 内容续接特惠、游玩、餐饮与住宿支持持续运营。
02

LOCAL COMMERCE

把商户信息、优惠套餐和到店服务放在一条决策路径中。

详情页先给出营业状态、价格、位置和服务标签，再承接套餐、商品、活动与商家介绍，帮助用户快速判断是否值得到店或购买。

  • 信息集中位置、营业时间、电话与服务标签一屏可见。
  • 优惠分层到店套餐、单品特惠和企业权益形成不同转化入口。
  • 内容增强图文介绍补充商户氛围和区域故事。
03

SCENIC TICKETING

景点购票拆分为详情、日期和票种三个稳定阶段。

用户先了解景点内容与价格，再选择日期、场次和数量，避免在同一页面一次性承担过多决策。

04

MAP EXPERIENCE

地图不是独立工具，而是连接生活分类和具体点位的主入口。

地图页在保持空间定位的同时，通过底部分类面板快速切换美食、旅游、民宿、购物、医疗教育和配套服务，并支持上滑展开列表。

  • 空间查找图标与点位建立清楚的区域分布感。
  • 分类切换生活类别以图形化入口快速切换。
  • 地图转列表上滑面板让用户从位置浏览进入内容浏览。
05

ENTERPRISE VIP

企业认证使用清晰的四步结构建立可信度。

用户依次选择所属企业、填写手机号、上传工作证件并确认认证结果，减少复杂表单带来的不确定感。

06

PROFILE & RIGHTS

个人中心区分普通用户和认证用户的权益状态。

页面集中订单、票券、收藏和认证入口，并通过积分、权益数量和 VIP 标识展示用户在平台内的身份与资产。

  • 状态可见普通与认证状态通过视觉和权益数据明确区分。
  • 资产集中订单、票券、收藏与积分在同一页面管理。
  • 认证引导未认证用户保留清楚的升级入口。

PROJECT SUMMARY

把生活地图、商户消费、票务和企业权益组织成一个可持续运营的生活圈平台。

项目通过统一的信息层级和交易结构，让用户可以在内容浏览、空间查找和权益认证之间自然切换。

当前功能说明基于页面进行初步整理，待全部项目完成后再统一校准业务描述与最终文案。
