# 西岸小梦 · UI、交互演示与作品集

默认打开 `index.html` 展示 PC 作品集首屏；`prototype.html` 为手机端交互演示。手机有效画布固定为 390 × 844 CSS 像素，按可用窗口整体等比缩放，边框不计入屏幕尺寸。所有底部弹窗在手机内部呈现。

- 手机演示的右上角、左下角「查看设计解析」均返回 `index.html#top`，即 PC 首页首屏。
- PC 首页右上角「手机端交互演示」、首屏「与小梦聊聊」、底部「开始体验小梦」均进入手机演示。`analysis.html` 保留为兼容入口。
- `screens.html`：仅展示当前设计，8 个模块、24 个关键页面。
- `modules.js`：页面分组与逐页分析的共用数据。
- 模块：停车、吃饭、订票、订酒店、行程、会员、活动、服务反馈。
- 每个模块呈现任务路径、3 个关键页面、逐页分析，以及用户体验／交互设计／产品体验说明。

启动：在本目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，浏览器打开 `http://127.0.0.1:8765/`。也可直接打开 HTML 文件。

这是一套无需构建的本地 HTML/CSS/JavaScript 情景原型。对话采用规则与预设分支，酒店、票务、价格及服务状态为演示数据，未连接真实交易、定位或客服系统。主原型的演示订单与行程保存在当前浏览器；作品集中的页面预览使用独立的内存状态，不修改主原型记录。

## 八条体验路径

1. 停车到达：余位比较 → 会员身份 → 减免与费用试算 → 地图切换 → 路线预览。
2. 美食优惠：人数口味 → 套餐 → 领券 → 详情 → 到店路线。
3. 活动探索：日期 → 兴趣筛选 → 详情 → 人数 → 模拟预约。
4. 亲子行程：同行人与时长 → 时间轴 → 换一站 → 雨天方案 → 保存与导出。
5. 会员权益：演示身份 → 今日额度 → 费用试算 → 停车路线。
6. 服务反馈：问题摘要编辑 → 确认提交 → 工单进度 → 已解决/未解决分支。
7. 酒店推荐：入住/离店日期 → 人数预算偏好 → 酒店比较 → 房型退改 → 核对订单 → 模拟预订 → 加入行程/取消。
8. 景点票务：游船/艺术展/亲子体验 → 日期场次 → 成人/亲子票 → 数量 → 总价 → 确认 → 模拟预订 → 行程/取消。

手机内右上角“•••”可打开全部场景和“我的演示订单”。

## 原型边界

这是可点击的情景原型，使用本地规则匹配及预设对话，不是已接入大模型的客服服务。可输入相关关键词，也可点击建议问题继续。

所有车位、价格、活动、酒店、距离、退改政策、订单和工单均为情景演示。酒店名称与房源是虚构案例。地图是手绘的功能关系示意，不是真实地图服务。原型不读取定位、不采集麦克风、不发起真实支付、预订、购票或客服工单。

优惠券、行程与模拟订单保存在当前浏览器的 localStorage，不会跨设备同步。原始 Figma 未被覆盖；本次优化页面以 HTML/CSS/JS 交付。

## 素材与规范

小梦形象、音乐和餐饮图片来自用户提供的 Figma 文件。原始 PNG 来自用户附件。图标为 Phosphor Icons 2.1.1（MIT），已保存为本地字体与 CSS。对外发布前由作品持有人确认原始素材使用权限。

品牌主色 #7055DC；正文 #262332；次级正文 #736E80。原型采用系统中文字体和原生语义控件；提供键盘焦点、弹窗焦点约束和 reduced-motion 支持。仅设计浅色主题。

## 上传个人作品网站

网站更新包的根目录包含 index.html。将解压后的全部文件与 assets 目录一起上传至目标网站目录，覆盖旧版同名文件即可。全部链接为相对路径，支持部署到个人网站的子目录，无需 npm 安装或构建。
