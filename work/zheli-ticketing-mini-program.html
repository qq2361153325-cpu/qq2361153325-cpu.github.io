ZHELI TICKETING · MINI PROGRAM

浙里票务
演出购票小程序

以演出内容发现为入口，把项目详情、日期场次、票档选择、实名验证、选座与订单管理串联为清晰的购票闭环。

Mini ProgramTicketingUX / UIContent Discovery
从“找演出”到“完成购票”覆盖高频内容消费与高压力购票场景
01 / PROJECT OVERVIEW

PROJECT BACKGROUND

为浙江地区演出用户，建立统一、快速的票务入口。

项目围绕演出浏览与购票场景展开。用户既需要按城市、时间和类型快速找到内容，也需要在热门演出开票时完成日期、场次、票档、实名与座位等连续决策。

设计重点不是单独美化页面，而是降低信息理解成本，在内容丰富度、购票效率与交易安全之间找到平衡。

Platform微信小程序

面向移动端演出消费场景

Scope全链路体验

发现、详情、购票、订单与个人中心

RoleUI / UX Design

信息结构、交互路径与视觉设计

Core高效决策

压缩热门票务场景的操作路径

DESIGN CHALLENGES

票务体验的难点，集中在三次关键决策。

01

先找到想看的内容

演出品类多、城市跨度大，首页需要兼顾运营曝光、分类浏览和个性化发现。

02

再判断是否值得购买

项目详情要同时呈现内容氛围、价格、场馆、服务保障、优惠和用户反馈。

03

最后快速完成购票

日期、场次、票档、实名、座位和库存状态必须在有限时间内被准确理解。

02 / EXPERIENCE MAP

FULL JOURNEY

将复杂票务流程拆解为六个连续阶段。

用户在每个阶段只处理当前最重要的信息，页面通过固定操作区、明确状态和渐进式披露减少反复确认。

01

CONTENT DISCOVERY

首页从功能聚合，逐步收敛为更强的文化内容入口。

最终方案以鲜明的戏曲主题建立地域文化识别，同时保留城市搜索、演出分类、抢票倒计时、专题推荐、演出日历和场馆入口。

  • 强运营首屏大幅主题 Banner 承载重点演出和城市文化表达。
  • 快速分类舞蹈、戏曲、音乐、亲子等高频品类一屏可达。
  • 分层内容抢票、专题、日历、榜单与推荐形成不同浏览深度。
02

CITY & LIST

用城市、日期和品类，帮助用户缩短搜索路径。

列表页强调演出海报、项目名称、时间、场馆、价格和状态标签。无演出日期时不留空白，而是继续提供猜你想看，保持内容探索连续性。

城市定位

搜索框与城市切换并列，明确内容归属。

状态清晰

预售、售罄、可选座等状态贴近价格区展示。

空态续接

无匹配结果时推荐相关演出，降低跳失。

03

EVENT DETAIL

将内容氛围与购票信息放在同一条决策线上。

详情首屏根据项目素材支持视频或静态视觉。核心价格、日期、场馆、服务保障和预约入口始终保持稳定，避免营销内容打断购买判断。

  • 视频氛围适合明星演唱会等高情绪内容，增强临场感。
  • 静态主视觉适合戏曲与舞台项目，保证项目信息识别效率。
  • 可信信息场馆地址、服务保障、抢票攻略和用户想看数据集中呈现。
04

TICKET DECISION

把日期、场次、票档和优惠拆成可扫描的选择层级。

选项采用标签与卡片组合，已选、可选、售罄和优惠状态通过颜色与边框区分。固定底部按钮同步显示当前选择和价格，减少用户回看。

渐进选择

只有完成上一步后才展开后续选项。

库存反馈

场次和票档直接显示剩余状态，避免无效点击。

价格透明

优惠标签贴近票档，最终金额持续可见。

05

SEAT & IDENTITY

在高压力购票环节，优先保证状态可见与操作确定性。

选座页面保留完整视野图、价格图例、已选座位和确认按钮。实名与抢票攻略提前承接规则说明，让用户在开票前完成准备。

  • 座位地图区域、价格和已选状态保持一致的视觉编码。
  • 实名校验在进入购票前解释身份信息用途与填写要求。
  • 抢票准备通过攻略和预设减少开票时重复输入。
06

ORDER & PROFILE

交易完成后，仍然保留清晰的订单回访路径。

个人中心以订单和常用票务服务为核心，减少与购票无关的信息干扰。订单列表通过状态筛选、演出摘要和操作按钮帮助用户继续付款、查看详情或处理售后。

状态优先

订单状态和可执行操作出现在同一视觉区域。

内容回忆

海报、场馆、日期与金额帮助快速识别订单。

常用服务

实名、地址、优惠和收藏集中在个人中心。

03 / DESIGN PRINCIPLES

用内容氛围吸引，用稳定结构完成交易。

项目在视觉上允许不同演出保持个性，但所有交易节点必须遵循相同的信息层级与状态规则。

01

内容先吸引

首页和详情用主题视觉建立情绪，关键购买信息始终清晰。

02

选择可扫描

日期、场次、票档和优惠使用一致的卡片与标签语法。

03

状态不含糊

可选、已选、售罄、无排期和待付款均提供明确反馈。

04

高压场景减负

通过实名、攻略和信息预设减少抢票时的输入与判断。

04 / SELECTED CORE SCREENS

CORE PAGE COLLECTION

精选 20 个核心页面，
展示票务产品完整覆盖度。

长页面在列表中统一展示单屏内容，点击后查看完整设计稿。页面按首页、发现、详情、购票和账户五类整理。

05 / PROJECT SUMMARY

从内容发现到订单管理，建立统一的票务体验框架。

本项目覆盖首页、城市频道、项目详情、日期场次、票档优惠、实名、选座、抢票攻略、订单与个人中心等关键场景。

设计通过“内容氛围负责吸引、结构规则负责交易”的方式，在丰富运营内容与高效率购票之间保持平衡，也为不同演出类型和后续业务扩展提供了稳定基础。
